# 上下文改写 Agent

## 目标

审核 Agent 负责找违规和证据；改写 Agent 负责把违规片段改成可直接口播的成稿，或给出明确的剪辑指令。

## 输入

- 完整口播和句级时间码
- 目标片段的原文、时间范围
- 前后各 2 句上下文
- 当前方法（TTS / 剪句 / Wan / 人工）
- 原片段时长
- 额外约束（更口语、更短、换卖点等）

## 输出

```json
{
  "action": "replace_script|cut_segment|manual",
  "after_text": "可直接口播的成稿",
  "edit_instruction": "剪辑或人工处理指令",
  "kept_selling_point": "保留的卖点",
  "estimated_duration_ms": 2600,
  "alternatives": ["备选 1", "备选 2"],
  "confidence": 0.86
}
```

- `replace_script`：UI 显示“口播文案”，`after_text` 可直接 TTS。
- `cut_segment`：UI 显示“剪辑/处理方案”，不再把操作说明塞进口播框。
- `manual`：必须人工处理。

## 约束

- 保留主播口吻和上下文衔接。
- 不新增功效，不重新引入违规词。
- 改写文案会再次经过规则复检；复检不通过则丢弃。
- 模型失败时回退原有建议，不阻断审核。

## 模型

- 通过 `BASE_URL1` 调用 `deepseek-v4.1-flash-1017`。
- `response_format=json_object`，带 JSON 修复和一次重试。

## UI

- 口播类：文本域展示成稿，另显示剪辑说明、保留卖点和备选文案。
- 剪辑类：单独显示琥珀色“剪辑/处理方案”框，不显示口播文本框。
- “刷新建议”会重新调用上下文改写 Agent。
