# 视觉审核评测

## 范围

- 24 条纯画面参考视频。
- 22 条带平台引文的审核记录，共 41 条画面引文。
- 模型：`qwen3.8-flash`，16 帧均匀采样，512px 宽。

## 指标

| 口径 | 命中 | 说明 |
| --- | ---: | --- |
| 严格引文匹配 | 2/41 | 要求模型描述与平台原句高度重合 |
| 类别覆盖 | 23/41 | 视觉事件类别与平台问题类别一致 |
| 类别+画面关键词 | 17/41（41.5%） | 类别一致且关键画面词有交集 |
| 类别覆盖记录 | 13/22（59.1%） | 至少有一条平台画面问题被类别覆盖 |
| 关键词覆盖记录 | 10/22（45.5%） | 类别和画面关键词都覆盖 |

## 结论

1. 视觉层已经能识别明显事件，例如 v03c8 的穿前/穿后腹部对比和局部裸露擦边。
2. 纯画面召回仍不足，主要原因是关键帧可能错过短暂动作，以及模型描述与平台原句的粒度差异。
3. 不应把严格引文匹配当成视觉主指标，类别和关键画面词更接近实际审核。
4. 视觉事件目前应作为候选和证据链，必须人工确认，不能直接自动放行或自动修改。

## 下一步

1. 关键帧改为“场景变化 + 均匀采样”混合，减少短暂极端拉伸/拉伸演示被漏掉。
2. 每个视觉类别给 1-2 个平台参考案例，让模型输出更接近审核语言的证据。
3. 增加一轮“画面描述 → 类别映射”的二次判断，避免描述正确但类别错误。
4. 对 24 条纯画面视频复测，目标把类别+关键词覆盖从 41.5% 提升到 70% 以上。
