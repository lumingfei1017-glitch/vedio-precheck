# 语义事件评测

## 范围

- 数据：42 条文本类参考视频。
- 标注：Excel 审核建议中的平台引文。
- 对比：规则快筛、语义事件证据、规则+语义合并。

## 结果

| 类型 | 引文数 | 规则命中（部分/完整） | 语义命中（部分/完整） | 合并命中（部分/完整） |
| --- | ---: | ---: | ---: | ---: |
| 文本/音频 | 91 | 80 / 61（87.9% / 67.0%） | 56 / 54（61.5% / 59.3%） | **86 / 80（94.5% / 87.9%）** |
| 混合 | 10 | 2 / 0 | 4 / 1 | 6 / 1（60.0% / 10.0%） |
| 画面 | 11 | 3 / 3 | 2 / 2 | 3 / 3（27.3% / 27.3%） |

“部分命中”表示命中引文中的至少一个分句；“完整命中”要求覆盖平台引文的全部主要分句。文本类 35 条记录中，合并结果有 34 条至少命中一条平台引文，34 条命中过半引文，31 条完整覆盖全部引文。

## 结论

1. 语义 Agent 单独用会丢召回，不能替代规则层。
2. 规则层保显性词和高置信兜底，语义层补跨句聚合和新表达，合并后效果最好。
3. 画面类召回仍低，必须另做关键帧、OCR 和视觉模型，不应继续加文本词。
4. 多句范围承诺必须按“完整命中”评估。v03c8 的 AP-06 已从只命中“90斤”修正为完整覆盖“150/120/90”三句，时间码 00:00.6-00:01.9。

## 验收用例

`v03c8eg10000dbuld1vog65j4akkb5rg`：

- 语义层：1 条事件“现场收腹演示叠加确定性塑形承诺”，带 6 条证据。
- 合并后：1 条语义事件 + 1 条独立的体型范围规则，共 2 条。
