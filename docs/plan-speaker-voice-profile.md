# 说话人分离与音色档案：Agent 计划

> 状态：方案待评审，未进入实现。
> 前置阅读：[plan-audio-block-replace.md](plan-audio-block-replace.md) §2.2（Wan 实测）、§11（兜底链）。
> S0 离线 spike 已完成：[spike-speaker-diarization.md](spike-speaker-diarization.md)。

## 0. 结论先行

当前"按素材取一份参考音、全片共用一个 voice_id"的做法，在多说话人素材上会直接把 B 的台词克隆成 A 的声音。这是硬伤，不是参数问题，必须先补说话人分离。

但**不要做全段重配**：TTS 的情感节奏撑不起整条口播，会把转化率打下来。正确路线是"按镜头归属说话人 → 每人一份音色档案 → 只在违规块内重配"。

Wan 路径单独处理：参考音是**可选增强**，短、同镜头、干净才加；加完台词变脏就去掉重跑。

## 1. 根因与现状

| 现状 | 问题 |
|---|---|
| `app/asr.py` 只有文本、词级与句级时间码 | 没有说话人字段，无法区分 A/B/C |
| `app/edit.py` 按 `material_id` 取一份 30s 参考音 | 多人素材会被混成一个音色 |
| 所有替换片段共用一个 `voice_id` | B 的台词会被配成 A 的声音 |
| 参考音固定截取首段连续 vocals | 可能跨场景、跨麦克风、混入多人 |

CosyVoice 官方建议参考音 10–20 秒、至少 5 秒连续清晰人声、整段不能混入其他说话人。**长度不是关键，同一人、干净、同场景才是关键**。

## 2. 范围（MVP 边界）

做：

- 单条素材内的说话人区分（A/B/C）
- 每个说话人一份参考音 + 一个 `voice_id`
- 按镜头归属说话人，镜头内出现换人时拆块或标人工
- 工作台展示说话人并可手动改绑

不做：

- 跨视频的声纹身份识别
- 全段重配
- 两人重叠说话区域的自动处理
- 硬字幕擦除

## 3. 数据模型

```text
speaker_segment
  material_id, start_ms, end_ms, speaker_key, confidence, overlap(bool)

voice_profile
  material_id, speaker_key, ref_path, ref_hash, ref_seconds,
  voice_id, created_at, quality_json
```

`speaker_key` 只用 A/B/C，在单条素材内稳定；不做全局身份。

## 4. 链路设计

### 4.1 说话人分离

输入：Demucs 的 `vocals.wav` + ASR 片段。

```text
vocals + 句子时间码
  → 每句取中间 1.5–3s（避开首尾）
  → CAM++ 提取 embedding（192 维）
  → 余弦相似度矩阵 → 层次聚类
  → 输出 speaker_segment（含 confidence 与 overlap 标记）
```

技术选型：本地 FunASR + CAM++，模型走魔搭 `iic/speech_campplus_sv_zh-cn_16k-common`。

环境：单独建 `diar-venv`，用 `--system-site-packages` 复用现有 CUDA Torch，不要装进 `demucs-venv`。

阈值：不照搬论文值。先用 20–30 对人工标注的同人/异人样本画相似度分布再定；经验区间是同人 >0.75、异人 <0.6。

短于 1.5s 的句子 embedding 不稳，直接标低置信度。

### 4.2 镜头归属

以镜头为归属粒度，不用单句：

1. 取镜头时间区间；
2. 统计镜头内各说话人的语音时长；
3. 主说话人 = 时长占比最高者；
4. **镜头内次要说话人占比 >20% 且连续 >2s → 在该时间点把替换块拆开**，分别绑不同音色；
5. 拆不开（重叠说话、切换频繁）→ 标"需人工指定音色"，不自动处理。

只按"时长最多"归属，会把镜头内的画外音绑到主播音色上，这条必须防。

### 4.3 参考音选取

候选池：该说话人的所有片段，逐条过滤：

- 不含违规词
- 无重叠说话
- VAD 语音占比 >60%
- BGM 残留低（`no_vocals` 能量占比低于阈值）
- 无削波

优先级（严格排序，不是并列）：

```text
同镜头 10–18s 干净片段
  > 跨镜头但同场景 15–20s
  > 同场景多段拼接 20s
```

跨场景不拼接：两段不同房间的 8 秒拼起来，克隆出来会有两种音色。

后处理：去首尾静音 → loudnorm 到 -18 LUFS → 16k 单声道 → 写 `data/voices/{material_id}-{speaker_key}-{hash}.wav`。

样本不足 8s 干净人声 → 不自动克隆，标人工。

### 4.4 voice_id 档案

缓存键：`(material_id, speaker_key, ref_hash)` 三元组。

复用条件三者全一致；参考音一变就重新克隆，旧的不再使用。A/B/C 绝不共用 `voice_id`。

## 5. TTS 路径

1. 违规块扩到"整句 + 前后各一句"，形成 5–12s；
2. 相邻违规块间隔 <3s 合并；
3. 块边界必须落在 ≥120ms 静音上，不切词中间；
4. **块内所有句子用同一 `voice_id` 重配，包括未违规句**——这是消除块内割裂的关键；
5. 按句生成、按原时间槽装配，句间保留原停顿，不整体变速；
6. 块边 30–50ms equal-power 交叉淡化，块外原样；
7. 块整体 loudnorm 到原块 ±2dB。

参考音质量就是 TTS 质量的天花板，这部分投入回报最高。

## 6. Wan 路径

Wan 的 `reference_video` 本身就是那个镜头，音频天然同人，所以它**不需要音色档案**，只需要一条输入安全规则：

| 条件 | 动作 |
|---|---|
| 同镜头、单人、4–8s 干净人声 | 附 `reference_audio` |
| 镜头内多人 / 无干净人声 / 音乐过重 | 不附，只留 `reference_video`，标记"音色可能偏移" |
| 跨镜头拼接的 20s 档案 | 不给 Wan |
| TTS 生成的音频 | 永远不给 Wan |

实测取舍：

| 版本 | 参考音 | 音色 | 台词 |
|---|---|---|---|
| A | 不给 | 290.9Hz，偏年轻 | 最干净 |
| C | 同场景 6s | 238.8Hz，与原声一致 | 开头多一个衬字 |
| B | 跨场景 6s | 258.1Hz | 3.2s 处切场景 |

所以策略是 **fail-open + 一次回退**：

```text
默认带 4–8s 同镜头参考音
  → 生成后 ASR 校验
  → 出现衬字/复读/串词，去掉参考音重跑一次
  → 两次都不过 → 判失败，进兜底链
```

宁可多一次调用换音色，也不接受为了音色把台词搞脏。

## 7. 明确禁止

- 把 TTS 输出当 Wan 的 `reference_audio`（会把平的韵律教给 Wan）
- 跨场景拼接做参考音
- 低置信度时静默选一个音色
- 对重叠说话区间自动替换
- 全段重配（情感节奏会全线崩盘）

## 8. 接口与工作台

```text
GET  /api/materials/{id}/speakers        # 说话人清单、时长占比、置信度
POST /api/materials/{id}/speakers/rebind # 手动把镜头改绑到某个音色
GET  /api/materials/{id}/voice-profiles  # 每个说话人的参考音与质量
```

工作台：

- 顶部显示"检测到 N 位说话人"与各自时长占比
- 每个违规块显示归属说话人、替换范围（含上下文几 句）
- 允许手动改块边界与改绑音色
- 每块显示音色相似度与门禁结果，不通过时可"扩参考音重试"

## 9. 验收标准

| 指标 | 目标 |
|---|---|
| 参考音 ≥8s 的说话人，违规区间归属正确率 | ≥95% |
| 全量归属正确率 | ≥90% |
| 静默误绑（把 B 配成 A） | 0 次（硬指标） |
| 低置信度与短样本被标记 | 100% |
| 块内音色一致性（TTS 块与原块 embedding 余弦） | ≥0.75 |
| 块边界爆音 | 0 |
| 盲听 5 条能对应回原人物 | ≥4 条 |

离线 spike 输出三样东西：带 `[A]/[B]` 前缀的 SRT、区间归属 JSON、与人工标注对比的混淆矩阵。只看"感觉对"不算通过。

## 10. 实施阶段

| 阶段 | 内容 | 预估 |
|---|---|---|
| S0 | 离线 spike：5–8 条真实素材（单人/双人/三人/音色相近/音乐重），出混淆矩阵 | 1 天 |
| S1 | `app/speaker.py`：embedding + 聚类 + 单测 | 1 天 |
| S2 | 参考音按 speaker 取 + 质量门禁 + `voice_profile` 表 | 1 天 |
| S3 | `edit.py` 接入：按镜头归属、块构造与合并、静音吸附 | 1 天 |
| S4 | Wan 路径接入：可选参考音 + 失败回退 | 0.5 天 |
| S5 | 接口 + 工作台展示与改绑 | 1 天 |

前三阶段不动现有渲染链路，出问题可随时退回单人逻辑。

## 11. 风险与回退

- 短句 embedding 不稳 → 低置信度标人工，不猜
- 重叠说话无法分离 → 判不可自动修改，走删段/人工
- 同性别不同人区分有限 → 阈值必须在真实素材上校准
- 参考音混入 BGM → 从 `vocals` 取并做残留检测
- 单人素材行为不变 → 检测为 1 人时走现有逻辑，保证兼容
