# 视频修改 MVP

## 已实现

- `edit_plan`：把审核建议转成可执行操作。
- 同一镜头内的相邻违规点先合并；覆盖镜头多数口播时扩到整镜，避免一句话拆成两段处理。
- 语义违规优先按 evidence 时间簇拆分，不再把两块相隔十几秒的证据塞进一个长替换区间。
- A 类（无删段）：片段级换音轨 + 字幕重排，目标区间外保留原音轨。
- A 类（分离不可用）：回退整轨 TTS，并明确报告 BGM 未保留。
- B 类：删除违规时间区间 + 视频拼接。
- Mixed：先删段，再把替换区间映射到新时间轴，只替换剩余目标片段的音轨。
- 后台渲染任务：进度、失败重试、输出下载。

## API

```text
POST /api/materials/{id}/apply?dry_run=true
POST /api/materials/{id}/apply?dry_run=false
GET  /api/materials/{id}/output
GET  /api/materials/{id}/output.srt
GET  /api/materials/{id}/shots?refresh=false
POST /api/materials/{id}/shots/replace   # {start_ms,end_ms,text,route,dry_run}
```

`dry_run=false` 返回 `job_id`，复用现有任务轮询。

### 镜头清单与整镜替换

- `GET /shots` 用场景切分 + 语音覆盖 + 人脸占比生成镜头清单，按素材缓存，命中后约 10ms。
- 每个镜头带 `kind`（口播特写 / 口播全身 / 侧身口播 / 画外音 / 无口播）和 `route`（wan / tts / keep / manual）。
- `POST /shots/replace` 的 `route=wan` 走整镜重生成；`route=tts` 只换本镜头口播，Demucs 保留原 BGM。
- `dry_run=true` 返回时长与文案密度预检；`false` 创建 `shot_replace` 任务，完成后写回 `render_output_path`。
- Wan 失败时后台自动尝试局部 TTS，并在结果中写 `fallback_from=wan` / `manual_review_required=true`。
- Wan 下载后先测实际时长；超过参考镜头 80ms 即拒绝回贴，避免发糊吞字。
- 工作台在视频下方展示镜头清单：`wan` 镜头可重生成，`tts` 镜头可局部换音轨。

## 当前模式

### A 类：片段级换音轨

- 读取每个违规区间，只对目标区间生成 TTS。
- Demucs 分离整条素材，目标区间用 `no_vocals` 回混，区间外直接保留原音轨。
- 从原视频连续 vocals 抽取 25–30 秒、去静音并标准化，按素材缓存为稳定参考音；后续重渲染复用同一个 `voice_id`。
- 克隆不可用时才走 Edge，并标记 `edge_fallback`。
- 多个不重叠区间按时间顺序逐个回贴，最终总时长保持不变。
- 输出 `output.mp4` 和 `output.srt`。

已知限制：

- Demucs 不可用时回退整轨 TTS，会明确报告 `BGM 未保留`。
- 目标区间内的原音效可能被 Demucs 归入 `no_vocals`，仍需抽检。
- 原视频硬字幕无法自动擦除。
- TTS 在 1.15x 内压不进目标时长时直接拒绝渲染，不再 `atrim` 硬切音频造成糊音。

### B 类

- 按 `cut_intervals` 删除片段。
- FFmpeg 精确剪切、重编码、拼接。
- 字幕按保留区间重排。

已知限制：

- 尚未接入 B-roll/产品镜头覆盖，当前是直接删段。
- 跳切可能明显，需要后续补镜头覆盖。

### Mixed

- 先删除违规画面区间。
- 把源时间轴上的替换区间映射到删段后的新时间轴。
- 与删段重叠的替换区间会自动缩短；不足 0.5 秒的残留区间跳过。
- 残留区间放不下对应文案时，整段并入删段，不生成只够说半句话的残片。
- 只对剩余目标区间做 TTS，其他区间保留删段后的原音轨和 BGM。
- 输出统一 MP4 + SRT。

## 实跑结果

- A 类：6 秒 demo，输出视频/音频均 6 秒。
- B 类：删除后 3 秒，输出视频 3 秒、音频 3.02 秒。
- Mixed：v03c8 输出 30.2 秒，删除两段违规区间后 TTS 合成完成。
- 片段级 TTS：30 秒真实素材只替换 10–14 秒，总时长 30.0 秒；0–9.5 秒相关度 0.9996，14.5–29.5 秒相关度 0.9997，目标区间相关度 0.332。
- 该次真实素材使用已创建的 CosyVoice 音色，`voice_source=cloned`、`bgm_preserved=true`；复检 ASR 为“这件平时穿比较贴合，日常搭配也省心。”
- Mixed 实测：83.7 秒素材删除扩大的违规区间后输出 71.537 秒；开头复检仍为原口播，目标区间复检为改写后的台词。
- 整镜合并实测：最后 5.5 秒镜头中的两处违规合并成一次改写，复检 ASR 为“慢慢就能找到适合自己的穿着状态，越穿越顺。”，不再拆成两次 TTS。
- 14–32 秒空音修复：语义证据簇改为 2.8–14.3 秒和 30.09–32.17 秒两段，14–32 秒复检恢复为有效口播，不再出现 18 秒只有 BGM 的空档。

## 镜头面板约束

前端镜头清单已经对应 Wan 硬约束：

- 每个镜头显示 `Wan 输出时长 / 参考时长`，输出不得大于参考。
- 参考时长不足 Wan 最短 2 秒时，直接标红并禁止提交，建议 CUT/人工。
- 显示字数预算区间（4.5–5.5 字/秒）和当前文案密度。
- 超出字数上限禁止提交；偏短会提示镜头末尾可能被原句填空。
- 新文案开头/结尾 5 个字与原句相同时提示复读风险，提交前二次确认。
- 显示“参考视频/音频：本镜头原声”，确保 Wan 参考来自同场景。
- “重生成”前先调用 dry-run，返回 `duration / char_budget / fit / warnings` 后再决定是否提交。
- TTS 镜头显示“换音轨”，不再提示未接入；失败时始终暴露 `edge_fallback` 或人工确认要求。
