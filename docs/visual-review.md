# 视觉审核层

## 模型与输入

- 模型：`qwen3.8-flash`
- 接口：与语义层相同的 `BASE_URL1` OpenAI 兼容 `/chat/completions`
- 输入：按时间均匀抽取关键帧，最多 12 帧，缩放到 512px 宽
- 输出：视觉事件 + 帧时间码 + 画面描述 + 修改建议

## 检查类别

- 低俗擦边：敏感部位特写、低角度、透视/暴露、内裤痕迹、刻意突出臀部或胸部
- 品牌混淆：第三方品牌 logo、商标、包装或明显模仿
- 夸张性能演示：极端拉伸、承重、暴力按压
- 身材对比演示：穿前穿后、腹部/臀部局部对比
- 其他明显视觉风险

自身品牌（当前为“北极绒”）正常出现在画面或字幕中不算品牌混淆。

## 合并规则

- 相同规则类型的相邻帧事件会合并成一条证据链。
- 不同规则类型即使时间重叠也保留为独立事件。
- 视觉事件以 `source=vision` 写入 finding，证据中包含 `frame_ms` 和 `frame_index`。
